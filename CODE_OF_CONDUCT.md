# Code of Conduct

## Our standard

Coder Conduit is a community experiment shared by Coder Radio listeners and
maintainers. Participation is open to everyone who engages constructively.

Expected behavior:

- Be respectful and factual in issues, PRs, and review threads.
- Critique code and ideas, never people.
- Accept maintainer decisions on scope, labels, and merges as final.
- Give the AI agents clear, honest input — they act on what you write.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language of any kind.
- Trolling, spam, or bad-faith submissions.
- Attempts to prompt-inject, "jailbreak," or otherwise manipulate the AI
  agents — whether in issue text, code, comments, commit messages, or file
  contents the agents may read.
- Deliberately wasting the project's token budget (e.g., flooding issues or
  triggering agents on junk input).

## Enforcement

Violations result in **immediate bans and closed PRs**, as stated in the
project README. Maintainers may remove, edit, or reject any contribution that
violates this code, and their decisions are final.

To report a violation, contact the maintainers privately rather than engaging
in-thread.

## Scope

This code applies in all project spaces — issues, pull requests, discussions,
and any community channel where the project is represented.
